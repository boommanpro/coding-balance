功能特性

⭕

圆形剩余指示

菜单栏以进度环直观展示近 5 小时剩余额度，颜色随余量变化：绿 ≥50%、橙 20–50%、红 <20%。

🗂

周 / 月额度明细

点击弹出详情：5h 大圆环主视觉 + 周/月统计，三个窗口的已用/剩余进度条与下次重置时间。

👥

多账户切换

支持多个账户同时配置，顶部选择器或账户列表一键切换当前使用账户，切换即刷新并记住选择。

🖱

左键详情 · 右键菜单

左键打开详情面板，右键呼出「刷新 / 管理账户 / 退出」快捷菜单，符合 macOS 使用习惯。

🔒

隐私安全

AK/SK 仅保存在本机，直接请求火山引擎官方管控面 API，不上传任何第三方服务器。

♻️

自动刷新

每 60 秒自动同步额度，接近用尽时进度条与指示环自动变红提醒。

界面预览

下载安装

1

下载应用

前往 GitHub Releases 下载最新的 CodingBalance-macOS-*.zip，解压后把 CodingBalance.app 拖入「应用程序」。

2

首次打开

应用为开发者自签名，首次打开需在「系统设置 → 隐私与安全性」中允许，或右键应用 → 打开。之后菜单栏右上角出现齿轮图标 ⚙。

3

配置账户

点击齿轮 → 添加账户 → 填入火山引擎 Access Key ID / Secret Access Key → 「测试连接」通过后保存，菜单栏即刻显示额度。

💡 想从源码构建？git clone 后执行 cd macos && ./make_app.sh（需 Swift 工具链，macOS 自带或 Xcode 提供）。

使用说明

🔑 获取 AK/SK

  1. 打开火山引擎 · API 访问密钥管理，登录火山引擎账号。
  2. 点击「新建密钥」，生成 Access Key ID 与 Secret Access Key（Secret 仅显示一次，请立即保存）。
  3. 建议使用 IAM 子账号并授予 ark:GetCodingPlanUsage 等方舟权限；主账号密钥亦可用。

🖱 交互方式

  • 左键：打开详情弹窗（5h/周/月额度 + 重置时间）
  • 右键：刷新 / 管理账户 / 退出
  • 多账户：弹窗内切换「当前使用账户」，状态栏随当前账户联动
  • 悬停：显示账户名与 5h 剩余百分比

❓ 常见问题

  • 显示 0 或错误？ 检查 IAM 是否有 ark:GetCodingPlanUsage 权限。
  • 数据来源？ 官方管控面 API（GetCodingPlanUsage / GetAFPUsage），与控制台 1:1。
  • 支持哪些套餐？ Coding Plan 个人版（百分比）与 Agent Plan 个人版（AFP 绝对值）。
